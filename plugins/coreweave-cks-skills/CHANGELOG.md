# Changelog — coreweave-cks-skills

Entries are written for someone deciding whether to run
`claude plugin update coreweave-cks-skills` today. Newest first.

This file ships inside the plugin, so an installed copy carries its own history.

Entries are drafted by release-please from Conventional Commits and land in a
release PR for a human to review before anything is tagged. Edit the entry in
that PR rather than here — see
[docs/RELEASING.md](../../docs/RELEASING.md).

## 0.1.0 — initial preview release

Tagged `coreweave-cks-skills-v0.1.0`. This is the first tagged release; everything before it was
untagged and never published as a release, so no entries are reconstructed for
it. That history is the git log.
