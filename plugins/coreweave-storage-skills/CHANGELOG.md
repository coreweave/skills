# Changelog — coreweave-storage-skills

Entries are written for someone deciding whether to run
`claude plugin update coreweave-storage-skills` today. Newest first.

This file ships inside the plugin, so an installed copy carries its own
history. For when and how to add an entry, see
[docs/RELEASING.md](../../docs/RELEASING.md).

## Unreleased

Nothing released yet.

## 0.2.0 and earlier — prerelease

Every version up to and including **0.2.0** is prerelease. They predate the
process in [docs/RELEASING.md](../../docs/RELEASING.md): no tag was cut, nothing
was published as a release, and no customer was ever told to update. Their
history is the git log, and no entries are reconstructed here.

The first release adds the first entry above.
